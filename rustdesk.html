Connect & Update Server

SSH into your DigitalOcean Droplet using your IP address. Once logged in, ensure your system packages are completely up to date.

bash Connect to Server
ssh root@YOUR_DROPLET_IP
bash Update Packages
apt update && apt upgrade -y
Step 2
2

Configure the Firewall (UFW)

RustDesk requires specific ports to operate correctly. We will open these ports and enable the firewall. Don't forget to allow OpenSSH so you don't lock yourself out!

bash UFW Rules
# Allow SSH connections
ufw allow OpenSSH

# Allow RustDesk ports
ufw allow 21115:21119/tcp
ufw allow 21116/udp

# Enable the firewall
ufw enable
Step 3
3

Install Docker & Docker Compose

We'll use Docker to package everything perfectly. Run the official installation script and enable Docker to start on boot.

bash Install Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh
systemctl enable docker
systemctl start docker
Step 4
4

Setup RustDesk Directory

Create a dedicated folder for your RustDesk configuration and encryption keys, then navigate into it.

bash Create Folder
mkdir -p /opt/rustdesk
cd /opt/rustdesk
Step 5
5

docker-compose.yml Configuration

Create the Docker Compose file using nano: nano docker-compose.yml. Paste the following configuration, then save with Ctrl+X → Y → Enter.

⚠️ Important: You MUST replace YOUR_DROPLET_IP with your actual server IP address in the configuration below.
yaml docker-compose.yml
version: '3'

networks:
  rustdesk-net:
    external: false

services:
  hbbs:
    container_name: hbbs
    ports:
      - 21115:21115
      - 21116:21116
      - 21116:21116/udp
      - 21118:21118
    image: rustdesk/rustdesk-server:latest
    command: hbbs -r YOUR_DROPLET_IP:21117 -k _
    volumes:
      - ./data:/root
    networks:
      - rustdesk-net
    depends_on:
      - hbbr
    restart: unless-stopped

  hbbr:
    container_name: hbbr
    ports:
      - 21117:21117
      - 21119:21119
    image: rustdesk/rustdesk-server:latest
    command: hbbr -k _
    volumes:
      - ./data:/root
    networks:
      - rustdesk-net
    restart: unless-stopped
Step 6
6

Launch Server & Get Key

Start the server in the background. Once it starts, RustDesk will automatically generate a public/private key pair. You need to print the public key to configure your local clients.

bash Start Server
docker compose up -d
bash View Public Key
nano ./data/id_ed25519.pub
Copy the string outputted by the command above. In your RustDesk client, go to Settings > Network, set the ID Server and Relay Server to your Droplet IP, and paste the string into the Key field.
